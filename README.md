**Stealth Idler** is a lightweight, high-performance Steam trading card and hour farmer built with Rust and Tauri. It gets the job done silently in the background with near-zero CPU and RAM usage, skipping the bloated Electron interfaces of older tools.

* **Tiny footprint:** Native Rust core and Tauri frontend keep system impact virtually unnoticeable while gaming or working.
* **Smart card farming:** Automatically queues card-eligible titles and idles them until all drops are in your inventory.
* **Custom hour boosting:** Idle multiple selected games simultaneously to boost playtime stats on your Steam profile.
* **Account-safe idling:** Emulates game states natively without running game binaries, rendering graphics, or injecting into memory.
* **Clean & modern UI:** Fast, responsive, and distraction-free desktop experience.
